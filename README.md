### ***1. маскировка цифр номера карты пользователя в формате: 8990 92** **** 5229***
```

```

- **Error_03** - не введён номер карты
###### Аргументы функции:
```

```
###### функция возвращает строку (str) скрытого номера карты:
```
 7000 79** **** 6361
```
##### В функцию импортирован модуль log_config.py который ведёт логирование этапов исполнения функции в директорию: logs/masks.log

- ```amount``` значение валюты, число с плавающей точкой ```float```, пример: 102.53
- ```currency``` строку с кодом валюты ```str```, пример: "USD"

###### адрес сервера API:
```https://marketplace.apilayer.com/```

##### алгоритм работы функции:
- если транзакция изначально в RUB, функция возвращает число в RUB
- если транзакция в USD или EUR, отправляет данные во внешний API-сервис для конвертации», функция возвращает число в RUB
- если при обработке транзакции или во время запроса к API происходит ошибка, функция возвращает число 0.0
- если на входе функции неверный аргумент - вместо словаря передан список, строка, число None или пустой объект, вернет 0.0

###### Аргументы функции:
```
    conversion_rub(amount, currency) 
```
###### функция возвращает:
- значение ```float``` пример: ```9250.45```
