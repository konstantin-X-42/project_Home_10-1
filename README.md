# Проект над виджетом банковских операций клиента.

## Описание:
Выкладываем проект на GitHub и ведем разработку по GitFlow.
Учитываем рекомендации PEP 8, используя линтеры делаем атомарные коммиты.

## Установка:
1. Клонируйте репозиторий:
    ```
    git clone https://github.com/konstantin-X-42/project_Home_10-1
    ```
   
2. Установите зависимости, идентичные по файлу poetry.lock:
    ```
    poetry install
    ```
   
## Использование:
**В проекте реализованы функции:**
### ***1. фильтрация по статусу***
        '''
        ```
        filter_by_state()
        ```
        '''

    функция принимает:
     - массив (список словарей или картеж словарей)
     - критерий фильтра массива по умолчанию - 'EXECUTED' или 'CANCELED' ключа 'state'.

    функция обрабатывает ошибки:
        ```
        'Error_11 - в аргументе функции, key в словарях или в одном из словарей отсутствует'
        'Error_12 - в функцию не подаются аргументы или поданы в ином формате'
        ```

    Входные данные функции:
    ```
    filter_by_state([{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
        {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
        {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
        {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}], 'CANCELED')
    ```

    функция возвращает отфильтрованый список словарей:
    ```
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
    {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
    ```

### ***2. фильтрация по дате***
        ```
        sort_by_date()
        ```

    функция принимает:
     - массив (список словарей или картеж словарей)
     - критерий фильтра массива, дата по умолчанию - True (убывание).

    функция обрабатывает ошибки:
    ```
    'Error_13 - в аргументе функции, key в словарях или в одном из словарей отсутствует'
    'Error_14 - в функцию не подаются аргументы или поданы в ином формате'
    ```

    Входные данные функции:
    ```
    filter_by_state([{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
        {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
        {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
        {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}], False)
    ```

    функция возвращает отфильтрованый список словарей:
    ```
    [{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
    {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'},
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}]
    ```
