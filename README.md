## Установка зависимостей:
1. Клонируйте репозиторий:
    ```
    git clone https://github.com/konstantin-X-42/project_Home_10-1
    ```
2. Установите зависимости, идентичные файлу poetry.lock если лока нет на основе pyproject.toml
    ```
    poetry install
    ```
### зависимости для тестирования, проверки стиля кода или отладки:

3. Установите библиотеку фреймворк pytest — инструмент для написания тестов
    ```
    poetry add --group dev pytest
    ```
4. Установите библиотеку для анализа покрытия кода при проведении тестирования
    ```
    poetry add --group dev pytest-cov
    ```

## **модуль masks.py**
### ***1. маскировка цифр номера карты пользователя в формате: 8990 92** **** 5229***
```
        get_mask_card_number()
```
##### функция в аргументе принимает:
- строку - str
- набор целых чисел - int

##### функция обрабатывает исключения:
- **Error_01** - ошибочное количество символов в номере карты
- **Error_02** - введён не допустимый тип данных или не числовой символ в номере карты
- **Error_03** - не введён номер карты
###### Аргументы функции:
```
    get_mask_card_number('7000792289606361')
```
###### функция возвращает строку - str скрытого номера карты:

###### 7000 79** **** 6361

## Тестирование

В проекте используется фреймворк `pytest` для проверки корректности работы функций и обработки ошибок.

### Запуск тестов
Для запуска всех тестов выполните:
```
poetry run pytest
```

### Анализ покрытия кода (Coverage)
Чтобы узнать, насколько полно код покрыт тестами, используйте `pytest-cov`:
```
poetry run pytest --cov=src
```

### Список проверяемых сценариев:
Проект включает в себя систему валидации данных с возвратом специфических кодов ошибок.

#### Работа с картами:
* **Error_01**: Ошибочное количество символов в номере карты.
* **Error_02**: Недопустимый тип данных или нечисловой символ.
* **Error_03**: Номер карты не введен (пустое значение).

#### Работа со счетами:
* **Error_04**: Ошибочное количество символов в номере счета.
* **Error_05**: Недопустимый тип данных или нечисловой символ.
* **Error_06**: Номер счета не введен (пустое значение).

#### Работа с датами:
* **Error_07**: В дате присутствует нечисловой символ.
* **Error_08**: Значения цифр за пределами формата даты (например, месяц > 12).
* **Error_09**: Передан недопустимый тип данных.
* **Error_10**: Передана пустая строка.

#### Тестирование filter_by_currency()
* **проверяем функциию на корректность фильтрации транзакций по заданной валюте.
* **Проверяем, функцию на правильную обработку случаев, когда транзакции в заданной валюте отсутствуют.
* **Проверяем, что генератор завершается без ошибки при обработке пустого списка или списка без соответствующих валютных операций.

#### Тестирование функции transaction_descriptions()
* **Проверяем, функцию что возвращает корректные описания для каждой транзакции.
* **Проверяем, работу функции с различным количеством входных транзакций, включая пустой список.

#### Тестирование генератора card_number_generator
Напишите тесты, которые проверяют, что генератор выдает правильные номера карт в заданном диапазоне.
Проверьте корректность форматирования номеров карт.
Убедитесь, что генератор корректно обрабатывает крайние значения диапазона и правильно завершает генерацию.
